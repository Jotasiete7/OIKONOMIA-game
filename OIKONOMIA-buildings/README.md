# 🎨 OIKONOMIA — Pasta de Entrega de Artes & Prédios (Buildings)

Coloque aqui os seus novos modelos renderizados e sprites em formato PNG com fundo transparente!

## 📁 Distribuição das Pastas:
* 🏘️ `residencial/`      -> Casas de subúrbio, mansões, prédios de apartamentos, torres residenciais.
* 🏭 `industrial/`       -> Fábricas de transformação, siderúrgicas, refinarias, tecelagens, montadoras.
* 🛒 `comercial/`        -> Supermercados, lojas de conveniência (kombinis), farmácias, vestuário, eletrônicos.
* 🌾 `agricultura/`      -> Fazendas de trigo, milho, algodão, gado de corte, laticínios, plantações.
* 🚢 `portuario/`        -> Portos marítimos, terminais de importação, docas com guindastes.
* 📡 `utilidade_publica/`-> Emissoras de TV, estações de rádio, torres de telecom, prefeituras.
* 🌳 `decoracao/`        -> Parques urbanos, praças, fontes, monumentos, árvores.
* 🛣️ `vias/`             -> Estradas retas em X/Y, curvas, cruzamentos e pontes.
* ⛏️ `minas/`            -> Minas de ferro, poços de petróleo, bauxita, ouro, extração de madeira.
* 🗺️ `terrenos/`         -> Tiles de chão (grama, terra fértil, areia, água rasa, água profunda, montanha).

## 📐 Padrões Técnicos:
* **Formato:** PNG 32-bit (Fundo Transparente).
* **Projeção:** Isométrica 2:1 (Câmera Ortográfica no Blender: X=60°, Y=0°, Z=45°).
* **Iluminação:** Luz vindo do Noroeste (canto superior esquerdo).
