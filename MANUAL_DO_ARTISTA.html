📐 1. Projeção Isométrica Dimétrica 2:1

Todos os tiles de terreno e edifícios devem obedecer à proporção matemática exata de 2 de largura para 1 de altura.

📏 Dimensões Padrão:

  • Tile Base de Terreno (1x1): 64 px (largura) × 32 px (altura).
  • Prédios Pequenos (1x1): Base 64×32 px / Imagem 64×64 até 64×96 px.
  • Prédios Médios (2x2): Base 128×64 px / Imagem 128×128 até 128×160 px.
  • Sedes / Portos (3x3): Base 192×96 px / Imagem 192×192 até 256×256 px.

💡 Regra de Iluminação:

  • Fonte de Luz: Superior Esquerda (Noroeste / Canto superior esquerdo).
  • Face do Topo (Telhado): Mais clara (Luz direta).
  • Face Esquerda: Tom médio neutro.
  • Face Direita: Sombreada / Mais escura.

🐙 4. Como Sincronizar via GitHub

Comandos para você e seu amigo compartilharem o código e os assets gráficos:

# 1. Enviar novas artes para o repositório: git add .
git commit -m "art: adicionados novos icones e sprites"
git push origin main
# 2. Seu amigo atualizar o projeto com as últimas alterações: git pull origin main
